## 2026-07-30 - Optimized Regex Replacement in agent_runtime_helpers.py
**Learning:** Found multiple sequential `re.sub` calls with uncompiled regular expressions used to strip various XML-like thinking tags in `strip_think_blocks`. This runs per message and compiles these expressions repeatedly. Furthermore, performing 5 consecutive regex string replacements adds parsing overhead that can be bypassed by combining them into one single `re.sub` call using capturing groups and backreferences.
**Action:** Consolidated the multiple tag removals (`<think>`, `<thinking>`, etc.) into a single pre-compiled `re.compile(r'<(think|thinking|reasoning|REASONING_SCRATCHPAD|thought)>.*?</\1>')` pattern initialized at the module level. This avoids repeated compilation and reduces the number of string replacement operations from 5 to 1.
