## 2026-07-11 - Module-level caching for dynamically generated Regular Expressions in React leaf components
**Learning:** Using `useMemo` for dynamically generated regular expressions inside highly repeated leaf components (like inline Markdown highlight nodes) caches per component instance. This means the regex is still compiled hundreds of times on initial mount, and adds significant React hook overhead.
**Action:** Use a module-level `Map` cache outside the React lifecycle for dynamic regular expressions based on primitive dependencies (like search strings). This ensures the regex is compiled exactly once globally per search query, vastly reducing execution overhead and memory usage. Also, prefer the "i" flag over "gi" when using `RegExp` with `String.prototype.split`, as `split` handles global matches inherently and reusing a stateful global regex can lead to `lastIndex` bugs.
