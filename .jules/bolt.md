## 2026-07-23 - Pre-compile Regexes in strip_think_blocks
**Learning:** The `strip_think_blocks` function in `agent/agent_runtime_helpers.py` is called very frequently to remove inline reasoning from stored content. It contained multiple `re.sub` calls with uncompiled string patterns, causing significant redundant compilation overhead. The codebase's Python Code Convention for Performance explicitly states to pre-compile static regular expressions at the module or class level to prevent this overhead.
**Action:** Pre-compiled all static regular expressions used in `strip_think_blocks` at the module level in `agent/agent_runtime_helpers.py`. Also applied the same `_THINK_BLOCK_RE` pattern to similar uncompiled regexes in `agent/chat_completion_helpers.py` to ensure consistency and optimal performance. Always check frequently called string processing functions for uncompiled regex patterns.
