## 2026-10-01 - Add accessible loading state and focus rings to AuthWidget
**Learning:** For loading states that solely rely on non-textual or punctuation-based visual indicators (such as an ellipsis `…` or a spinner) without descriptive text, an explicit `aria-label` is needed on the container to ensure the context is accurately communicated to assistive technologies. Additionally, simple inline buttons like "Reload page" in error states need explicit focus-visible styles to remain keyboard accessible.
**Action:** Always provide an explicit `aria-label` (e.g. `aria-label="Loading authentication status"`) on containers that have `aria-busy="true"` but lack descriptive text. Ensure inline buttons have `focus-visible:outline-none focus-visible:ring-1 ...` for keyboard navigability.
