## 2026-07-16 - Add ARIA labels to icon-only buttons inside wrapper links
**Learning:** When an icon-only `<Button>` (such as one rendering only an `<ExternalLink />` icon) is wrapped inside an `<a>` tag that provides a `title`, the button itself still requires an explicit `aria-label` attribute and should be excluded from the tab sequence with `tabIndex={-1}` for proper accessibility compliance. The nested interactive element HTML structure also shouldn't technically be used, but ensuring it is labelled provides better screen reader experience.
**Action:** When implementing links that contain interactive UI components (like `<Button size="icon">`), ensure the innermost component has a descriptive `aria-label` and `tabIndex={-1}` to prevent redundant focus and properly describe the icon's purpose.
