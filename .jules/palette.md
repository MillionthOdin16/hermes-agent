## 2026-10-19 - Adding icon to LanguageSwitcher
**Learning:** Found that the LanguageSwitcher button is an icon-only button when collapsed but it does not have a visual icon. So if it is an icon-only button and missing the icon, it could just be an empty button or a very small button that causes usability and accessibility issues.
**Action:** Added `Globe` icon to `LanguageSwitcher` to make it clear what the button is.
