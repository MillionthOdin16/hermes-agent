## 2026-07-10 - Fix Icon-only Link Accessibility\n**Learning:** When an icon-only interactive element (such as a <Button>) is nested inside a wrapper link (<a> tag), the innermost interactive element needs its own `aria-label` attribute to be correctly identified by screen readers, and additionally should be explicitly removed from the tab sequence with `tabIndex={-1}` to prevent redundant tab stops. Nesting a <button> inside an <a> tag is technically invalid HTML in the first place, but we fix the immediate accessibility and redundant tabstop if we can't restructure the DOM.\n**Action:** Add `aria-label` to the innermost button, and `tabIndex={-1}` to prevent double-focusing when nesting button-looking elements inside links.
