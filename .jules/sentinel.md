## 2026-06-11 - Prevent credential leakage in `shell.exec` gateway method
**Vulnerability:** The `shell.exec` method in the TUI gateway executed user-provided commands via `subprocess.run(..., shell=True)` without sanitizing the environment variables. Because the gateway process often holds sensitive API keys and credentials in its `os.environ`, any shell command executed through this method could potentially access and leak these credentials.
**Learning:** Even when `shell=True` is intended and necessary for the feature (e.g., executing arbitrary user commands), the execution context must be isolated. Inheriting the parent's full environment in a security-sensitive gateway process creates a critical exposure point for credential theft.
**Prevention:** Always use `build_subprocess_env()` or a similar environment sanitization mechanism when spawning subprocesses that execute user-controlled commands, ensuring that sensitive credentials are not passed down to the child process.
