## 2026-09-04 - Prevent Credential Leakage in TUI Gateway Shell Execution
**Vulnerability:** The `shell.exec` command handler in `tui_gateway/methods_tools.py` uses `subprocess.run` with `shell=True` without explicitly specifying an environment mapping. This causes the child process to inherit the parent process's `os.environ`, which inside the TUI gateway context, contains all sensitive credentials (like `HERMES_API_KEY`, `TELEGRAM_BOT_TOKEN`, etc.).
**Learning:** Whenever shelling out via `subprocess` in a process that hosts sensitive API keys globally, the environment must be sanitized. Relying on default inheritance exposes secrets to any shell command executed by the user or agent. The `build_subprocess_env` factory in `tools.environments.local` is designed for this exact purpose.
**Prevention:** Always explicitly pass `env=build_subprocess_env()` when invoking `subprocess.run` or `subprocess.Popen` in any context where `os.environ` might hold unscrubbed credentials, especially when processing dynamic or user-driven commands.
