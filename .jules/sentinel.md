## 2026-09-26 - Mitigating Credential Leakage in Shell Execution
**Vulnerability:** Command injection / credential leakage through `shell=True` execution in `tui_gateway/methods_tools.py` during `shell.exec`. The environment wasn't adequately sanitized, leaving credentials accessible to the executing shell command.
**Learning:** Even though `shell.exec` correctly intends to run shell commands (making `shell=True` expected), the environment variables injected into the subprocess must be rigorously scrubbed to prevent accidental or malicious exfiltration of sensitive information (like API keys) held by the gateway process. The memory guideline confirms this: 'When securing `subprocess.run(..., shell=True)` calls (e.g., `shell.exec`) by sanitizing the environment with `build_subprocess_env()`, accurately label the PR and journal entries as mitigating "Credential Leakage" rather than fixing "Command Injection"'.
**Prevention:** Always use `build_subprocess_env(scrub_secrets=True)` when executing shell commands on behalf of users in the gateway process to ensure sensitive environment variables are sanitized.
