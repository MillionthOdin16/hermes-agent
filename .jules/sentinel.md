## 2026-05-18 - Prevent Command Injection Credentials Leak in TUI Gateway
**Vulnerability:** The `shell.exec` method in `tui_gateway/methods_tools.py` was executing commands using `subprocess.run` without an explicit environment (`env`) supplied. Because the TUI runs with environment variables containing all API credentials, this exposed the gateway's sensitive credentials to arbitrary executed commands.
**Learning:** Even when dangerous commands are blocked by pre-execution safety modules, any subprocess execution without a sanitized environment can inadvertently leak sensitive process-level secrets (like API keys) to the child process environment. Other subprocess commands in `tui_gateway/methods_tools.py` properly sanitize their environment before executing.
**Prevention:** Always inject a sanitized environment via `build_subprocess_env()` into all subprocess invocations, especially those processing potentially untrusted commands or those executed in privileged gateway layers.
